САХАЛИН: ПРИРОДА И МОРСКОЕ НАСЛЕДИЕ

Откройте index.html в современном браузере. Для интерактивной карты требуется подключение к интернету: картографическая основа загружается с OpenStreetMap.

Путеводитель содержит 10 остановок, поиск по названию и местности, интерактивную карту и избранное в браузере.
